Before You Begin — Prerequisites

Work through this checklist before the session. Most items take 5 minutes each.

Prerequisites

  • Claude account — use existing or sign up at claude.ai/login
  • Docusign developer account with Admin rights — use existing demo or create one at docusign.com/developers/sandbox
  • Docusign Demo URL bookmarked — apps-d.docusign.com
  • Download workshop kit — sample agreements, workflow, document templates, and other supporting files
⚠️
Sample exercise — demo data only

This is a sample exercise with synthetic / mock data. Use only with Developer / Demo accounts. Do not use Production accounts for this exercise.

1

Connect Docusign to Claude

🔌
Published connector points to Production

Docusign has a published connector in Claude that points to Production. To configure a demo environment, follow the steps to create a custom connector outlined here: developers.docusign.com/platform/mcp-server/anthropic-claude/.

Once connected

Switch to the account you'll be using for this workshop

If you're a member of multiple Docusign accounts, make sure Claude is connected to the demo / developer account you've prepared for this workshop — not Production and not a different sandbox.

Verify with a test prompt

Start a new chat and paste the prompt below. Claude should respond with your sandbox account name and email — confirm it is the demo account, not Production.

Test prompt Verify connection
What Docusign account am I connected to?

If you're a member of multiple Docusign accounts, you can also ask Claude to list all of them and then switch to the one you'd like to use for this workshop.

List accounts Optional
List all Docusign accounts I have access to.
Switch account Optional
Switch to my [ACCOUNT NAME] Docusign account.
Verify the tools available in the Docusign MCP connector

In Claude Settings → Connectors → Docusign, review the list of tools exposed by the connector. For each tool, customise the preference based on how you want Claude to act on your behalf:

  • Always allow
  • Needs approval
  • Blocked
  • Or set a custom rule
2

Set Up Your Docusign Sandbox

Log into your Docusign demo / developer account at apps-d.docusign.com. This is separate from any Production account.

From the left navigation, confirm Agreement Manager, Workflow Builder, and Agreement Desk are all available under the Agreements tab. If any are missing, contact your PSA to enable them.

🛠
Next: three quick setup tasks

To finish preparing your account, you'll:

  1. Upload sample agreements to Agreement Manager
  2. Import the renewal workflow into Workflow Builder
  3. Validate the document template

All files are in the workshop kit.

3

Upload Sample Agreements to Agreement Manager

In the Agreements tab, go to Agreement Manager → Completed in the left navigation, and upload the sample agreements provided in the workshop kit.

Wait a few minutes for AI processing to complete before moving on.

4

Configure Agreement Desk

In the Agreements tab, go to Requests in the left navigation and turn on Agreement Desk. In Agreement Desk Settings, copy the email address — you'll reference it later when routing the renewal workflow.

Agreement Desk has more configurations available — request types, agent settings, routing rules — but these are out of scope for this exercise.

5

Import the Workflow

In the Agreements tab, go to Workflows in the left navigation and import the workflow provided in the workshop kit. You can build one from scratch, but the import is provided for quick reference and testing.

Once imported, edit the workflow and update the Agreement Desk routing email ID as needed. Then Save, Review, and Publish.

⚠️
Workflow must be Published, not Draft

Claude can only trigger published workflows.

6

Validate Document Templates

In the Templates tab, go to Document Templates in the left navigation and confirm the template used in the workflow is available. If it is not, import it from the workshop kit.

This template is what the workflow will use to generate the Order Form envelope.

7

Verify Setup

Back in Claude, validate that the agreements are available and the workflows are available.

List agreements Agreement Manager
List all my agreements.
List published workflows Workflow Builder
List available Workflow Builder workflows.
💡
Sanity check before proceeding

If Claude can list your agreements and your published workflows, your setup is complete and you're ready to start the scenarios. If either comes back empty, revisit the earlier setup steps before continuing.

Initial Context Prompt — Paste This First

🎬
Use case for this exercise

You are an Account Executive at Fontara, a B2B SaaS company. As with any sales persona, you are busy and manage a portfolio of customer accounts. You work in Claude and would love to get things done from one place instead of switching systems and manually verifying, copy-pasting deals, drafting Order Forms, or chasing compliance teams for approvals. Let's see how the Docusign connector in Claude automates this with accuracy.

Open a new chat and paste this prompt, or create a Project and paste it into the Project Instructions. If you're working in Cowork, you can also save it as a Skill with your own preferences.

💬
What this prompt does

It sets your role, anchors Docusign as the source of truth, enforces Workflow Builder-first execution, and locks in the response format for everything that follows.

▶️ Paste this as your first message
Role & context I'm an Account Executive at Fontara, a B2B SaaS company. I manage a portfolio of customer accounts. Our flagship product is Fontara Operate, sold at a list price of $1,430 per seat per year. How I want you to work 1. Source of truth — Docusign. For any question about agreements, customers, renewals, pricing, or clauses, query the Docusign connector directly. Never rely on assumptions or prior chat context for live agreement data. 2. Workflow Builder before eSign. When sending an agreement, always check for an available Workflow Builder workflow first and use it if one applies. Fall back to a direct envelope from an eSign template only when no suitable workflow exists. 3. Response format. Keep responses brief, accurate, and visually scannable: - Use tables for any comparison, list of agreements, or financial breakdown - Use visual indicators — ✅ in place / compliant · ⚠️ at-risk · 🔴 missing or non-compliant · 🕐 pending - Lead with a one-line summary, then the detail - Show calculation workings before any final dollar figure - Never fabricate data — if a field isn't in Docusign, say so Confirm you've got it, then wait for my first question.

Scenario A — Agreement Insights

Agreement Manager IRIS

The story: You're the AE at Fontara. The customer is asking for an expansion of seats with a discount. Before you say yes, you need to know what's in place, what's at risk, etc.

What you'll demonstrate

  • Pulling a portfolio-wide view of upcoming renewals across multiple customers
  • Agreement Manager extracting party names, dates, key insights, terms and clauses etc. from agreements
  • Cross-account clause checks — does a 15% discount violate any MFN or price-protection language?
  • SmartFactory (missing AI Addendum + DPA) vs FutureSkills (compliant) as a natural contrast

Run these prompts in order

A1 — Portfolio renewal view Agreement Manager · IRIS
Show me all upcoming renewals across my book of business in the next 180 days.
A2 — Account-level account overview Agreement Manager · IRIS
For SmartFactory Systems, which documents are active and in place today? List key details
A3 — MFN / discount clause check Agreement Manager · IRIS
SmartFactory Systems is interested to expand to 300 seats and is asking for a 15% discount. Does offering 15% to SmartFactory violate any pricing commitments or clauses with another customer?
A4 — Cross-account compliance comparison Agreement Manager · IRIS
Compare SmartFactory and FutureSkills side-by-side on compliance posture and clauses. Show me what SmartFactory is missing that FutureSkills has in place.
B

Scenario B — Workflow Builder Orchestration

Workflow Builder Agreement Prep eSign

The story: You're cleared to offer the 15% discount. SmartFactory wants to expand from 150 to 300 seats. The renewal will be a 1-year term (no multi-year on this deal). Time to trigger the Workflow Builder renewal workflow and get the Order Form in front of the customer signer.

Run these prompts in order

B1 — Build the deal math Calculation
Work out the SmartFactory expansion deal: 300 seats at $1430 list price with 15% discount
B2 — Initiate the renewal (the core prompt) Workflow Builder
Initiate a renewal for SmartFactory Systems for 300 seats with 15% discount for a 1 year term starting June 1, 2026. Route it to [recipient email] at SmartFactory.
C

Scenario C — Track Workflow and Agreement Status

Workflow Builder Agreement Desk eSign

The story: The Order Form was sent. A few minutes later, you check in to see where things stand. You need to track the workflow, see what's pending signature, and nudge the recipient if needed.

C1 — Check workflow status Workflow Builder
What's the status of the SmartFactory renewal workflow instance? Which step is it on, who needs to act next, and is anything blocked?
C2 — Signature status on the SmartFactory envelope eSign
Has the recipient at SmartFactory signed the renewal Order Form yet? When was it sent and has it been opened?
C3 — Send a reminder eSign
Send the SmartFactory recipient a signing reminder through Docusign — use the existing envelope, don't create a new one. Then tell me when the envelope expires and what happens if it's not signed by then.
👥
Human in the Loop

Notice the workflow has deterministic routing — if the discount is more than 15%, it routes to Agreement Desk for a manual review and approval. The Agreement Desk process can be customized as per your business needs.

Congrats — You Built This!

You've connected Docusign to Claude, set up the demo account, and run the three core scenarios end-to-end. Use the resources and prompts below to extend the use case and put it through its paces.

Homework — extend with CRM and Maestro

Now that the agreement layer is wired up, try extending it on either side — pulling deal context in from CRM, or pushing executed agreement data back out.

EXTENSION 1
Pull from CRM into the workflow
Connect a CRM MCP (or use a Maestro step) to fetch signer name and email, opportunity TCV, seat count, and discount tier directly from the opportunity — no copy-paste from chat.
EXTENSION 2
Push executed agreement data back to CRM
Once the Order Form is signed, update the CRM opportunity — stage to Closed-Won, attach the executed PDF, update license count and ACV on the account.
EXTENSION 3
Smarter Agreement Desk routing
Add additional routing rules in Maestro / Agreement Desk — e.g. deal-desk approval for discounts >15%, legal review for non-standard clauses, CRO sign-off above a TCV threshold.
EXTENSION 4
Custom approval policies
Configure Agreement Desk request types and reviewer assignments to mirror your real org structure — approvers, SLAs, escalation paths.
💡
Test ideas to try

Trigger the workflow with a discount above 15% and verify it routes to Agreement Desk. Then trigger one below the threshold and confirm it goes straight to signature. Swap the recipient email mid-workflow. Cancel a workflow instance. Test what happens when the template is missing.

Troubleshooting

IssueLikely causeFix
I don't see any agreements in your account Connected to production instead of sandbox, or Agreement Manager extraction not complete Reconnect MCP with sandbox credentials. Wait 3–5 min per doc. Ask Claude: What Docusign account am I connected to?
Agreement Manager fields are blank or partial Extraction still running, or unsupported file format uploaded Click Re-analyze. Wait 5 minutes.
Workflow Builder workflow doesn't appear when Claude queries Workflow is in Draft, not Published status Go to the Agreements tab → Workflows in the left navigation → open the workflow → click Publish. Wait 60 seconds.
Claude can't find document templates No templates exist in the sandbox Go to the Templates tab → Document Templates in the left navigation → import or create the template from the workshop kit.
MCP shows Disconnected in Claude settings OAuth token expired Settings → Integrations → Docusign → Disconnect → reconnect with sandbox credentials.
Envelope send fails with an error Required template fields not populated, or sandbox email restrictions Try with a different email. Try sending it manually with the same values.
Claude cannot find or list clauses or terms Agreement not processed fully, or clause not available in Agreement Manager Validate the agreement and extraction in Agreement Manager and create a custom extraction as necessary.
Workflow errors out in the "Set up an Invite" step Invalid or mistyped recipient email Check that the email address of the recipient is correct and valid, then retry the workflow.
Latest agreements are not visible (account is correct) Claude is referencing previously fetched data from earlier in the chat Ask Claude to refresh the list of agreements (e.g. Refresh the list of agreements from Docusign.) so it re-queries Agreement Manager.
Workflow not initiated, though Claude says it was initiated successfully Workflow trigger inputs from the request didn't satisfy the workflow's required fields Check the workflow trigger inputs from the request. Try different values, or trigger the workflow manually in Workflow Builder to identify the issue.
