Start in three steps

1

Connect Docusign

Your admin turns on MCP access, then adds the Docusign connector to your AI tool. Production is the default. Demo accounts use a custom connector.

2

Browse prompts

Pick your role on the Prompts page, copy a prompt, replace the [brackets] and run it. Read-only prompts answer straight away.

3

Add a skill or build an agent

Install the core skill once so answers follow our rules. Then add team skills, or build an agent that runs them on a schedule.
