Content standards

What every submitted lab should include so it is reusable by any PSA.

Clear outcomeOne sentence on what the attendee builds.
Prerequisites listedAccounts, licences, sample files, access.
Copyable blocksPrompts, JSON and schemas as copy-ready code.
Test inputs + expected resultKnown inputs, so success is checkable.
Guardrails sectionWhere a human stays in the loop, and what fails safe.
Screenshots + recapKey steps shown, with a closing summary.
